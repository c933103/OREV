Portable Windows x64 build of OpenRouter Export Viewer 0.1.6. Extract the ZIP and launch **OpenRouter Export Viewer.exe**.

- Reopening a changed JSON at the same path now asks before refreshing its folder. The warning shows the full path and how many checked conversations would be cleared.
- **Keep current version** is the default. **Refresh folder** loads the updated contents. Identical files keep their selection and checks without a prompt.

The Windows package includes the source, the OREV Community License 1.1, and third-party notices. This is an unsigned build.
