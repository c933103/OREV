Portable Windows x64 build of OpenRouter Export Viewer 0.1.7. Extract the ZIP and launch **OpenRouter Export Viewer.exe**.

- Open exports, checked and selected conversations, reading position, title filter, and metadata panel state autosave locally and restore on restart.
- OREV asks before reopening a changed file and keeps missing or skipped entries for retry. The session stores file references and viewer state. Your conversations and images are read from the original export files.
- Use **Session → Start new session** to clear saved state.

The Windows package includes the source, the OREV Community License 1.1, and third-party notices. This is an unsigned build.
